# IU ResultHub — WT Mini Project

Student Result Management System built with HTML, CSS, JavaScript, PHP and MySQL-compatible MariaDB.

**Full editable source** is in [Student_Result_Management_System.zip](Student_Result_Management_System.zip), including `index.php`, `assets/style.css`, `assets/app.js`, database bootstrap, Dockerfile, startup script, and detailed README.

Render deployment uses the root Dockerfile to extract the project archive.

**Note:** The free-tier demo includes an embedded ephemeral MySQL-compatible database. Student data resets when the free instance sleeps/restarts. Configure an external hosted MySQL server for durable storage. This is an academic project, not an official university results portal.
